# 🖥️ TrasMaTech-MonitorOverlay

**TrasMaTech-MonitorOverlay** is a transparent always-on-top web content overlay for Windows – ideal for displaying real-time dashboards, status panels, announcements, or other web-based visuals across one or more screens without interfering with user interaction.

---

## 🚀 Features

- 🪟 Transparent, frameless overlay window
- 📡 Displays live content from a user-defined URL
- 🖱️ Mouse and keyboard passthrough – won't interfere with your desktop or applications
- 🧩 Multi-monitor support – choose which screen to display on
- 🧭 Width modes: full screen, left 50%, or right 50%
- 🌐 Language support (English, Norwegian – more coming)
- 🔁 Optional auto-refresh interval
- 🌙 Opacity adjustment (0%–90%)
- 🔔 Auto-update with GitHub integration
- 📥 Manual update check via system tray menu
- 📂 Remembers URL and settings between sessions
- 🔒 Enforces single-instance only

---

## 💡 Use Cases

- Game information overlay for gamers
- Wall displays in offices, factories, studios or control rooms  
- Information screens at events or reception desks  
- Silent real-time status monitors for dev teams or broadcast operators  
- Passive browser-based visualizations or slideshows  

---

## 📦 Installation

Download the latest installer from the [Releases page](https://github.com/tommyrsk/TrasMaTech-MonitorOverlay/releases/latest).  
Once installed, the app will appear in the system tray.

---

## 📋 How to Use

1. Right-click the tray icon.
2. Choose **“Change URL”** and enter the web address you want displayed.
3. Optionally:
   - Adjust transparency
   - Set refresh interval
   - Move overlay to another screen
   - Change display width (full, left/right 50%)
   - Manually check for updates
4. The overlay appears over everything else, but won't block mouse or keyboard input.

---

## 🔄 Updating

The application checks for updates automatically. You can also right-click the tray icon and select **“Check for Updates”** to trigger it manually. Updates are downloaded and installed seamlessly.
